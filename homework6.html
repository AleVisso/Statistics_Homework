Riemann vs. Lebesgue Integration & Standard Normal CDF Computation

Exercise 1: Riemann vs. Lebesgue Integration and Numerical Approximations

Integration theory provides formal frameworks to compute the "area under a curve" or, more generally, measure-theoretic expectations. The two primary paradigms differ fundamentally in how they partition space:

Riemann Integration (Domain Partitioning)

The Riemann integral partitions the domain interval $[a, b]$ into subintervals $[x_{i-1}, x_i]$ of width $\Delta x_i$. It evaluates the function at sample points and sums rectangular areas:

$$ S = \sum_{i=1}^n f(x_i^*) \Delta x_i $$

Numerical Approach: Quadrature rules (Trapezoidal, Simpson's) refine domain subintervals. Highly efficient for continuous and smooth functions but fails when discontinuity sets are dense or have positive measure.

Lebesgue Integration (Range Partitioning)

The Lebesgue integral partitions the range of function values into measurable subsets $E_i$ and considers the measure of their preimages in the domain, $m(f^{-1}(E_i))$:

$$ L = \sum_{i} y_i \cdot m\left(x \in [a,b] \mid f(x) \in E_i\right) $$

Numerical Approach: Binning function values in the codomain and computing domain measure (e.g., via Monte Carlo sampling or indicator counting). Robust against highly discontinuous pathological functions.

Analysis of Pathological Functions

  • Dirichlet Function: $f(x) = 1$ if $x \in \mathbb{Q}$, $0$ if $x \notin \mathbb{Q}$ on $[0,1]$.
    Riemann: Upper sums equal 1, lower sums equal 0 for any partition; thus not Riemann-integrable.
    Lebesgue: The preimage of $1$ is $\mathbb{Q} \cap [0,1]$ (measure 0), and the preimage of $0$ is irrational numbers (measure 1). The Lebesgue integral evaluates to $1 \cdot 0 + 0 \cdot 1 = \mathbf{0}$.
  • Thomae's Function (Popcorn Function): $f(x) = 1/q$ if $x = p/q$ in lowest terms, $0$ if irrational on $[0,1]$.
    Riemann: Discontinuous at every rational, but the set of discontinuities is countable (measure zero). Therefore, Thomae's function is Riemann-integrable with integral equal to $0$.
    Lebesgue: Yields the identical result ($0$) because rational points form a measure-zero set.
