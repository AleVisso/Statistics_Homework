Comparative Analysis: Toy ECC Scheme vs. Caesar Cipher

Evaluation of encryption/decryption mechanisms, key roles, and structural properties using the toy elliptic curve parameters developed in Homework 1 (\(E/\mathbb{F}_{17}: y^2 \equiv x^3 + 7 \pmod{17}\), base point \(G(1,5)\), subgroup order \(n=9\)).

Toy ECC Scheme (ElGamal Variant)

  • Private Key (\(k\)): Secret scalar chosen from \([1, 8]\). Example: \(k = 3\).
  • Public Key (\(P\)): Derived via scalar multiplication \(P = k \cdot G = 3(1,5) = (5,9)\).
  • Encryption: Select ephemeral scalar \(r\). Compute \(C_1 = r \cdot G\) and \(C_2 = M + r \cdot P\).
  • Decryption: Recover plaintext point via \(M = C_2 - k \cdot C_1\).

The Caesar Cipher

  • Key (\(s\)): Fixed shift integer in \([0, 25]\).
  • Encryption: Shift alphabet characters forward modulo 26: \(C = (P + s) \bmod 26\).
  • Decryption: Shift characters backward modulo 26: \(P = (C - s) \bmod 26\).
  • Mathematical Basis: Elementary modular linear substitution over character sets.

def break_caesar(ciphertext):
    english_freq = [0.082, 0.015, 0.028, 0.043, 
                    0.127, 0.022, 0.020, 0.061, 
                    0.070, 0.002, 0.008, 0.040, 
                    0.024, 0.067, 0.075, 0.019, 
                    0.001, 0.060, 0.063, 0.091, 
                    0.028, 0.010, 0.024, 0.001, 
                    0.020, 0.001]
    best_shift, min_chi = 0, float('inf')
    for shift in range(26):
        decrypted = decrypt(ciphertext, shift)
        chi = compute_chi_square(decrypted, english_freq)
        if chi < min_chi:
            min_chi, best_shift = chi, shift
    return best_shift
Effectiveness and Limitations: Statistical cryptanalysis is highly effective on long ciphertexts because letter counts converge closely to language expectations. On short ciphertexts (e.g., single words or short phrases), statistical anomalies cause false positives, requiring n-gram scoring or dictionary validation.

Toy ECC Attack vs. Real ECC Security

1. Attack on the Toy ECC Scheme

Because our toy curve restricts the subgroup order to \(n=9\), the private key space is limited to \(k \in [1, 8]\). An attacker can recover the private key instantly through exhaustive search (brute-forcing scalar multiples \(1G, 2G, \dots, 8G\) until matching public key \(P\)).

2. Structural Differences: ECC Attack vs. Statistical Attack

The attack against the toy ECC scheme is an algebraic brute-force search over a small discrete cyclic group, whereas the attack against the Caesar cipher is a statistical frequency analysis exploiting human linguistic redundancy and monoalphabetic preservation.

3. Infeasibility on Real secp256k1 ECC

In a properly configured secp256k1 curve, the private key space is \(2^{256}\) (\(\approx 1.15 \times 10^{77}\)). Exhaustive search is physically impossible due to astronomical energy and time constraints (governed by Landauer's principle and thermodynamic limits), ensuring that the Elliptic Curve Discrete Logarithm Problem (ECDLP) remains computationally intractable.
