Theoretical Analysis: OWF vs. CHF

Clear cryptographic distinction between general mathematical one-way requirements and specific hash function security properties.

One-Way Function (OWF) Properties
  • Pre-image Resistance: Computationally infeasible to find input \(x\) given output \(y\).
  • Second Pre-image Resistance: Hard to find a distinct second input mapping to the same output.
Cryptographic Hash Function (CHF) Properties
  • Collision Resistance: Infeasible to find any pair of distinct inputs yielding the same digest.
  • Arbitrary Input Length: Accepts messages of varying sizes into fixed-size outputs.

Official Subgroup Table \(\langle G \rangle\) & Order Explanation

Why we stop at \(n=9\): In elliptic curve cryptography over finite fields, the subgroup generated by base point \(G\) follows cyclic algebraic closure. Adding \(G\) iteratively for 9 times results in the point at infinity (\(\mathcal{O}\)), which serves as the identity/neutral element of the group (\(8G + G = \mathcal{O}\)). Beyond \(n=9\), the sequence repeats periodically, confirming that the subgroup order is exactly \(n=9\).
